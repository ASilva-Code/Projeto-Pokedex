# Projeto - Pokédex

Uma Pokédex feita para praticar e aprimorar conhecimentos de HTML, explorando a criação de páginas estruturadas, organizadas e visualmente agradáveis com uma abordagem simples.

## Sobre o projeto

O **PokePedia** é um projeto de estudo desenvolvido com o objetivo de praticar HTML na construção de páginas web.

A proposta é criar uma **Pokédex organizada**, apresentando informações sobre diferentes Pokémon de forma clara, intuitiva e visualmente bonita.

O projeto prioriza o uso de **HTML puro**, utilizando apenas o **mínimo necessário de CSS** para melhorar a apresentação e a organização dos elementos.

## Objetivos

- Praticar a estrutura básica e semântica do HTML.
- Aprender a organizar informações em páginas web.
- Trabalhar com imagens, links, tabelas, listas e outros elementos HTML.
- Desenvolver uma interface simples e agradável.
- Utilizar CSS apenas quando necessário para complementar a estrutura HTML.
- Criar um projeto prático para acompanhar minha evolução no desenvolvimento web.

## Tecnologias utilizadas

- HTML5 — estrutura e conteúdo das páginas.
- CSS3 — utilizado de forma mínima para estilização e organização visual.

> A ideia do projeto é evitar frameworks e bibliotecas externas, mantendo o foco no aprendizado dos fundamentos do HTML.

## O que a Pokédex apresenta

Cada Pokémon pode possuir informações como:

- Nome
- Número na Pokédex
- Imagem
- Tipo
- Descrição
- Habilidades
- Status
- Altura
- Peso

## Projeto de aprendizado

O PokePedia é principalmente um **projeto de prática**. A intenção não é criar uma aplicação complexa, mas sim aprender na prática como construir páginas utilizando os fundamentos do desenvolvimento web.

Com o avanço do projeto, novas páginas e funcionalidades podem ser adicionadas para continuar explorando os recursos do HTML e, posteriormente, do CSS.
